👉 Tu enlèves la charge mentale + tu valorises leurs ingrédients

---

## 🚀 LES 3 PILIERS DU BUSINESS

### 1. 🏠 SERVICE "PLACARD → ASSIETTE" (Le cœur du concept)

**Le client** :
- A la flemme
- Placard plein de truc random
- Veut une expérience

**Ce qu'on fait** :
- On arrive
- On regarde frigo + placard
- On improvise / propose des recettes
- On cuisine sur place

**💥 Valeur perçue** :
- Gain de temps (30-45 min max)
- Effet "wow" (créativité visible)
- Créativité (surprise culinaire)
- Zéro gaspillage (rien ne se jette)

**Tarif** : **30€ — 80€ par session**

---

### 2. 🍱 PLATS PRÉPARÉS REVISITÉS (Version scalable)

**Le concept** :
- On récupère les ingrédients clients ou surplus locaux
- On propose des plats signature OXFOOD
- On transforme le "basique" en "WOW"

**Exemples** :
- "Riz oublié → bowl créole revisité"
- "Boîte de thon → tacos fusion"
- "Restes légumes → velouté premium"

**💥 Tu passes de service → produit**

**Tarif** : **Menu simple** (10€/pers) | **Menu famille** (18€) | **Premium** (25€)

---

### 3. 🔄 REVALORISATION INTELLIGENTE (Ton ADN)

**Philosophie** : Rien ne se perd, tout se transforme

**Exemples** :
- Pain dur → croûtons / pudding salé
- Fruits mûrs → jus frais / compote
- Restes viande → wraps / sauces premium

**💥 Tu deviens une marque engagée** (storytelling puissant)

**Tarif** : **30€ — 60€ par session**
